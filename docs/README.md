# docs/ — 設計ドキュメント

このフォルダは **「何を作りたいか」と「なぜそう決めたか」** を置く場所。
`CLAUDE.md` は「今どうなっているか」（現状のアーキテクチャ・規約）を書く場所なので、
将来の方針・構想・未決定事項はこちらに書く。

## 読む順番

| ファイル | 内容 |
| --- | --- |
| [vision.md](vision.md) | **最重要。** ゲームの3本柱とコアループ。まずこれを読む |
| [audio-design.md](audio-design.md) | 音源のレイヤー構造、PDJEでの実現方法、音源調達の選択肢 |
| [progression-design.md](progression-design.md) | スキルツリー、排他スキル、プレステージ、メタプログレッション |
| [decisions.md](decisions.md) | 決定済み／未決定の一覧。**着手前にここで前提を確認する** |

## 表記ルール

ドキュメント内では以下を明確に区別する。将来のセッションが
「ユーザーが決めたこと」と「Claudeが提案しただけのこと」を取り違えないため。

- **【確定】** — ユーザーが明示的に決めた方針。勝手に変えない
- **【提案】** — Claude 側の設計案。ユーザー未承認なので変更・却下してよい
- **【要検証】** — 外部API・未確認の挙動。実装前に必ず裏を取る

## 更新のしかた

方針が変わったら、このフォルダを更新してから実装に入る。
特に [decisions.md](decisions.md) は「同じ議論を蒸し返さない」ための記録なので、
決定したら必ず追記する。
