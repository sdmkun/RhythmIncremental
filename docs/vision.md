# ビジョン — このゲームで一番やりたいこと

## 3本柱【確定】

このプロジェクトの中心にある「やりたいこと」は次の3つ。
**機能の優先順位で迷ったら、この3つに寄与するかで判断する。**

### 1. スキルを取ると曲のジャンルが変わる

スキルツリーの進行が、そのまま**鳴っている音楽の変化**として返ってくる。
単なる数値強化ではなく、「ビルドを組む＝曲を作る」という体験にする。
排他スキルになる可能性あり（House を選んだら DnB は取れない、など）。

### 2. プレイとスキルで音源にエフェクトがかかる

コンボ・精度などの**プレイ内容**と、取得した**スキル**の両方が、
リアルタイムに音へフィルタ／エコー／ディストーション等として反映される。
「上手く叩けている＝音が良くなっていく」フィードバックループ。

### 3. 1曲完成でプレステージ → メタプログレッション

スキルを取り切って**「1曲として完成」**したらプレステージ可能。
スキルツリーはリセットされ、代わりに恒久的な変化が残る
（例：初回はアンロックできなかったスキルが解禁される）。

## コアループ

```
   ┌─────────────────────────────────────────────────┐
   │                                                 │
   ▼                                                 │
プレイする ──> Beats を稼ぐ ──> スキルを取る ──> 曲が変化する
   │                                  │                 │
   │                                  │                 │
   └──── 音が良くなる/難度が上がる <───┘                 │
                                                        │
                            全レイヤーが埋まる = 1曲完成 │
                                      │                 │
                                      ▼                 │
                              プレステージ ─────────────┘
                            (ツリーリセット + 恒久解禁)
```

## 「1曲完成」の定義【提案】

曲を**レイヤー（ステム）の集合**として定義し、
全スロットが埋まった状態＝完成、とするのが素直。詳細は
[audio-design.md](audio-design.md) と [progression-design.md](progression-design.md)。

例：`Drums` / `Bass` / `Chords` / `Lead` / `Atmosphere` の5スロットを
すべて何らかのジャンルで埋めたらプレステージ解禁。

この定義の良いところ:

- 「完成」が音として体感できる（スカスカ → フルアレンジ）
- 排他スキル（＝各スロットのジャンル選択）と自然に噛み合う
- プレステージ条件が数値の閾値ではなく**構造的な達成**になる

## 現状とのギャップ

今あるもの（[../CLAUDE.md](../CLAUDE.md) 参照）:

- 4レーン落ちものリズムゲーム（動作する）
- Beats 経済 + Yggdrasil スキルツリー（動作する）
- **音源なし**（`Conductor` は無音でもクロックだけ回る設計）

3本柱すべてが「音」を前提にしているので、
**最初のマイルストーンは音を鳴らすこと**。
柱1・柱2は音源が鳴っていなければ何も始まらない。

推奨する着手順:

1. 音を鳴らす（ループ1本でよい）→ [audio-design.md](audio-design.md)
2. レイヤーの ON/OFF を実装 → 柱1の骨格
3. スキル → レイヤーのマッピング → 柱1の完成
4. FX をスキル/コンボに接続 → 柱2
5. プレステージ → 柱3
